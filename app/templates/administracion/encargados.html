Cómo funciona el tope
  • Los aportes (O.S. 3 %, Jubilación 11 % y Ley 3 %) se descuentan turno por turno mientras al encargado le falten más de {{ estado.margen|ars(0) }} para el tope del mes.
  • Cuando le faltan {{ estado.margen|ars(0) }} o menos, los turnos siguientes van sin esos aportes (se puede pasar del tope). El aporte sindical 3 % se descuenta siempre.
  • Cada mes arranca de cero. El margen se cambia en Administración → Fórmulas.
  • «Superó el tope» sirve para marcar a mano que un encargado ya pasó el tope este mes (por ejemplo, cuando el sistema arranca con el mes empezado): sus turnos del mes van sin esos aportes, sin necesidad de cargar el tope.
